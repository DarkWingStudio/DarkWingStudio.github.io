# Rohit Kumar - Portfolio

A minimal, modern portfolio website built for Rohit Kumar, a Frontend Developer & Creative Technologist. This project showcases selected works, technical skills, and a design-first approach to building web interfaces.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org) (React 19)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Typography:** Syne & Space Grotesk (via Google Fonts)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🎨 Design Philosophy

- **Aesthetic:** Dark mode default, high contrast, noise texture overlay.
- **Motion:** Subtle, meaningful entrance and hover animations using spring physics.
- **Typography:** Bold headers paired with clean, readable sans-serif body text.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `/app`: Next.js App Router configuration and pages.
- `/components`: Reusable UI components (`Hero`, `Work`, `About`, `TechStack`, `Process`, `Contact`, `Navbar`).
- `/data`: Static content data (e.g., project details).
